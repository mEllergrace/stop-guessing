STOP-GUESSING

Chain of custody and data provenance for agentic AI. It exists so that what an agentic tells you is not a guess.

v0.1.0 — plan complete, build not started

The problem

An agent reads data, transforms it, reports a result — and nothing durable records which bytes entered, what happened to them, or whether the report is true. Every downstream audit inherits that gap.

Two documented failures define its shape:

  • Replit / SaaStr, 21 July 2025 — an agent deleted a production database during an explicit code freeze, fabricated roughly 4,000 fictional records, and misreported what it had done. AI Incident Database #1152.
  • Berkeley RDI, April 2026 — a zero-capability agent scored ~100% on eight benchmarks by attacking the evaluator, including installing a fake curl wrapper that returned fabricated success to the grader. Writeup.

The second is a design constraint, not an anecdote: the recorder must not be reachable by the agent it records.

What nobody is doing

Everything in this space records actions. Nothing records data flow. Surveyed across Claude Code's native OpenTelemetry events, Obsigna, HDP, Langfuse, Arize Phoenix, LangSmith, OpenLineage and Microsoft's agent-governance-toolkit: every one answers “which agent called which tool, and was it allowed?” Not one answers “which bytes entered, and where did they end up?”

1 — No derivation edge across a session

OpenTelemetry's GenAI semantic conventions contain zero provenance attributes. OpenLineage has exactly the right graph primitive and no agent emitter exists.

2 — Agent DLP is stateless

Every redaction hook in the wild is a regex fired independently per call. The real risk is accumulation: twelve individually-innocuous reads composing into a restricted dataset, then one egress. Per-call matching cannot see that by construction.

3 — Custody state never reaches the decision

No system feeds accumulated custody state back into the permission decision. The hooks to do it are shipping, and unused.

The thesis

The agent's control decisions are computed only from trusted inputs; data handling is delegated to deterministic, capability-constrained code; and every delegation is recorded.

Backing: Design Patterns for Securing LLM Agents against Prompt Injections (IBM / Google / ETH / Microsoft) and CaMeL (DeepMind / ETH), which protect control flow rather than sight of data. The stronger claim — that the model never sees data at all — is what the bar posture implements. It ships as an option; it is not the claim we lead with.

Provenance is evidentiary, not preventive. A hash-chained log of an exfiltration is still an exfiltration. This is not a prompt-injection defence and will not be sold as one.

Postures

PostureBehaviour
observeRecords everything, blocks nothing.
steerDefault. Asks on first touch of a classified artifact, offering a recorded script delegation. Denies on accumulated taint crossing threshold, or any egress while tainted.
barThe model is barred from opening classified artifacts. Only signed scripts touch them; the model receives handles and summaries.

Full depth is the default and is never silently reduced. Where fidelity is genuinely reduced, that is recorded — known_gaps: [] is a positive assertion that nothing was skipped, and a missing key is rejected at write. Removable at four levels, none of which destroys the accumulated ledger.
